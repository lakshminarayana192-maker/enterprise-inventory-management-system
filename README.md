# Enterprise Inventory Management System

## Overview

The Enterprise Inventory Management System is a web application designed to manage products, warehouses, inventory, suppliers, customer orders, payments, and reports.

This project is being developed using modern enterprise technologies and follows real-world software development practices such as Agile, Git workflow, Docker, CI/CD, and Kubernetes deployment.

---

## Features

* User Authentication
* Product Management
* Inventory Management
* Warehouse Management
* Supplier Management
* Purchase Orders
* Customer Orders
* Payment Integration
* PDF Report Generation
* Notifications
* Dashboard and Reports
